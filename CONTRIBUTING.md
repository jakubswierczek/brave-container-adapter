# Contribution policy

This personal project does not accept issues or pull requests. Both features are
disabled on GitHub. There is no general support channel or response-time commitment.

Code, documentation and project-owned artwork use the [MIT license](LICENSE).
You may fork and modify the project under those terms. For local development, read
the [development guide](docs/development.md) and [repository instructions](AGENTS.md).

Report security vulnerabilities through the private channel in the
[security policy](SECURITY.md). Do not include personal browser data, complete URLs,
generated destination apps or signing credentials in reports.
